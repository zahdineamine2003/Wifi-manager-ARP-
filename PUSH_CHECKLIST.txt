🎥 RECORD VIDEO (Save to demo/ folder):
───────────────────────────────────────────────────────────────────────────────
□ kick_operation_demo.mp4    - 30-60 second demo of kick feature

STEPS:
1. Open WiFi Manager and scan network
2. Press Windows + G (Game Bar)
3. Click Record button
4. Select a device (NOT your PC!)
5. Click kick button
6. Show confirmation dialog
7. Set duration to 30 seconds
8. Click Yes
9. Show "Kick started" message
10. Wait 10 seconds
11. Click "Stop Kick"
12. Show "Kick stopped" message
13. Press Windows + Alt + R to stop recording
14. Save to demo/ folder

📝 IF YOU GET AUTHENTICATION ERROR:
═══════════════════════════════════════════════════════════════════════════════

GitHub requires Personal Access Token:

1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Give it a name: "WiFi Manager Upload"
4. Select scopes: ✓ repo (all), ✓ workflow
5. Click "Generate token"
6. COPY THE TOKEN (you won't see it again!)
7. When git asks for password, PASTE THE TOKEN

Save your token somewhere safe!
