🎯 PROCHAINES ÉTAPES (VOUS)
─────────────────────────────

1. Testez immédiatement:
   python test_units.py

2. Lancez l'app:
   python main.py
   (Admin sur Windows / sudo sur Linux)

3. Effectuez un scan:
   - Entrez CIDR local (auto-détecté par défaut)
   - Cliquez "Scan"
   - Attendez 15-30 secondes
   - Voyez les appareils!

4. Exportez les résultats:
   - Cliquez "Export CSV"
   - Choisissez le dossier
   - Fichier créé avec timestamp

5. Compilez pour distribution (optionnel):
   pip install pyinstaller
   pyinstaller --noconsole --onefile --name "WIFI_Manager" main.py
   # → dist/WIFI_Manager.exe
